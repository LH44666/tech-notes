Image Processing Notes — Glossary (REF-1013-C)

This glossary (REF-1013-C) accompanies the batch-processing notes and lists the terms used throughout them.

TermReferenceNote
Parameter snapshot—A complete configuration record at one point in time.
Rollback point—A version that can be safely returned to.
Verification IDREF-1013-CIdentifier of this document; retained whenever it is quoted.
Read-only configuration—A configuration file that the script does not modify at runtime.

A dash in the reference column means the term is not numbered separately and inherits the document number. Verification IDs are assigned by the document maintainer and stay unchanged across revisions.

When these notes are quoted elsewhere, the document number is kept alongside the quotation so that the original revision can be located later.
