Revision Log — Image Processing Notes (REF-1013-E)

This revision log (REF-1013-E) collects the changes made to the image-processing working notes. It records conclusions only, not the process behind them.

Each change was pushed by a specific problem. Parameters were first hard-coded in the script, so every adjustment meant editing code. Moving them into an external file fixed that, but then nobody tracked the configuration itself. The compromise that stuck was to keep the configuration under version control and make the script read it without writing back.
